# Virtual Reading World — Vision

Virtual Reading World is a calm, browser-based shared space where readers gather to read together.

The primary activity is reading. Social interaction happens only during natural breaks.

This is not a social network, not a forum, and not a game with points or competition.

## Core Principles

- Reading comes first
- Calm over engagement
- Presence over messaging
- Minimal UI clutter
- No feeds, likes, followers, or notifications

## Experience Goal

A user enters a peaceful ocean beach scene, sees a few other readers, and feels like they are quietly sharing a space with them.

They can:
- Walk their avatar around the beach
- Set up a personal reading corner (umbrella + book info)
- View other readers’ current book and status
- Send predefined prompts (not full chat initially)
- Save and restore their session state

## Milestone 1 Scope (Single Player)

- One static ocean beach scene
- One user at a time (no multiplayer yet)
- Avatar movement (click-to-move or WASD)
- Persistent profile stored in backend
- Reading corner saved and restored
