# Virtual Reading World — Milestones

This file captures the planned product milestones so they stay visible and easy to reference.

## Milestone 0 — Infrastructure

- Create `/world`
- Deploy the React app
- Connect it to the existing Node.js backend
- Verify deployment on the Google Cloud VM

## Milestone 1 — Single Player

- Static ocean beach scene
- One avatar
- Avatar movement (click or WASD)
- Persistent profile
- Persistent reading corner

## Milestone 2 — Shared Presence World

- Multiple concurrent readers in one scene
- Shared avatar movement and positioning
- Reader presence and leave behavior
- Active-reader count display
- Configurable active-reader limit
- Current-reader highlighting

## Milestone 3 — Reading Community

- Reader profile cards
- Reading status
- Current book
- Favorite authors
- Predefined prompts and stored responses
